How to put tonight's build on your iPad, what to try with the Apple Pencil, and what to send back. The build is the native app with our own board engine, the maths brain and the Blocks design system. The tutor, Ask and the real screens come next.

You're already set up for this. Your paid Apple Developer team (Rushil Chopra, SG4YJW2K5Z) is signed in to Xcode and set on the project. A signed build for real iPads already compiled. Your iPad has been paired with this Mac before.

Run it on your iPad

  1. Open the project in Xcode

    It's on branch feat/ipad-app. If Xcode says the project changed on disk, choose to reload it.

    open ~/whiteboardstaging/ipad-app/ios/Agathon.xcodeproj

  2. Plug in the iPad and unlock it

    Tap Trust if it asks. It needs iPadOS 17 or later.

  3. Pick the iPad as the destination

    In the bar at the top of Xcode, the scheme is Agathon. Click the device next to it and choose your iPad instead of a simulator.

  4. Press Run (⌘R)

    The first build takes a few minutes; later ones are quick.

  5. Allow it on the iPad, first time only

    If it asks for Developer Mode: Settings › Privacy & Security › Developer Mode › On, then let it restart and press Run again. If it says Untrusted Developer: Settings › General › VPN & Device Management › trust "Apple Development: Rushil Chopra".

  6. Open the Labs

    The app opens on a plain sign-in screen. You don't need to sign in: tap Labs in the bottom-right corner and pick a lab. Close (bottom-right) brings you back.

Careful with sign-in Sign-in on the iPad uses your real production account. The plain boards list after sign-in can rename and delete real boards. The Labs never touch the server.

If something goes wrong

The iPad isn't in the device list
Unlock it, check the cable, and look in Window › Devices and Simulators. Tap Trust on the iPad if it asks again.
"Signing for Agathon requires a development team"
Click the Agathon project › Signing & Capabilities › Team › Rushil Chopra. It's already set in the project, so this should only happen if Xcode lost the account.
Package or "missing module" errors
File › Packages › Reset Package Caches, then build again.
"Could not launch" or Developer Mode errors
Turn on Developer Mode (step 5) and restart the iPad.
Want to skip the cable next time
After the first run, Window › Devices and Simulators › your iPad › Connect via network. Then it runs over Wi-Fi.
